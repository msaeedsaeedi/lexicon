# Lexicon v0.1.0 contract

This release is a build-time lexical data pipeline. Its canonical dataset stores language
knowledge only: languages, sources, lexemes, forms, senses, definitions, and examples.

The `vocab` word/definition/example shape is generated only by `export-legacy`; it is not a
canonical input or storage model. Learner mastery, review history, scheduler state, and desktop
application settings do not belong in these artifacts.

The seed source is deliberately curated and immutable. Builds do not access the network. Future
source importers must first map their source-specific data into staging records, then use the
same normalization, validation, and compilation contract.
