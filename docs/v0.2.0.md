# Lexicon v0.2.0 — Open English WordNet

v0.2.0 publishes the first substantial Lexicon dataset: the complete common-word edition of Open
English WordNet 2025. It includes OEWN nouns, verbs, adjectives (including satellite adjectives),
adverbs, and multiword expressions; it excludes the 2025+ proper-name extension.

## Reproducible source boundary

`data/sources/oewn-2025.lock.json` pins the distribution URL, SHA-256, release, license, and
attribution. `lexicon acquire-oewn` may access the network only to place that exact archive in the
ignored `.cache/raw` directory. `lexicon import-oewn` and all subsequent build steps are offline
and fail if the archive checksum differs from the lock.

## Canonical mapping

The importer converts native WNDB data files into generic staging data. Every OEWN lemma/POS is a
Lexicon lexeme; every associated synset is a sense. OEWN synset identifiers are preserved as
`source_sense_key`, while Lexicon primary IDs remain source-neutral. Gloss definitions and quoted
usage examples are imported; WordNet pointer relations are intentionally not published yet.

The `0.2.0` schema adds raw-source checksums and sense source keys. v0.1 artifacts remain valid
historical bundles, but a consumer must only open schema versions it explicitly supports.

## Attribution

Open English WordNet is released under CC-BY 4.0. Each OEWN bundle includes source metadata,
`ATTRIBUTION.md`, `manifest.json`, `import-report.json`, and `release-manifest.json` so the raw
source, import counts, and distributed artifacts can be audited together.
