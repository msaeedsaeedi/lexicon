# Lexicon v0.1.2 release contract

v0.1.2 closes the first Lexicon release line. It freezes the canonical schema at `0.1.0` and
publishes dataset and pipeline version `0.1.2`.

Run the release workflow with:

```bash
uv run python scripts/release.py
```

The workflow creates a new `dist/lexicon-en-core-0.1.2` directory only after formatting, lint,
type, test, build, compatibility-export, checksum-manifest, and bundle-verification steps pass.
It refuses to overwrite an existing release directory.

`release-manifest.json` checks every file in the bundle. `manifest.json` continues to describe the
canonical dataset artifacts and their source provenance. The Vocab consumer contract is documented
in `docs/consumer-contract.md`.
