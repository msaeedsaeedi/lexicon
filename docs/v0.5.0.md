# Lexicon v0.5.0

This release adds deterministic English lemma frequency rankings from wordfreq 3.1.1, NGSL 1.2,
curation, and the `en-general-starter` collection. Schema 0.3.0 adds `rankings`, `collections`,
`collection_members`, `curated_lists`, `list_members`, and `curation` without changing the
existing canonical tables.

The starter collection is the filtered intersection of NGSL, clean curation, and a Zipf >= 2
rarity gate. It is ordered by stable NGSL position, never a learning schedule. The bundle also
contains `en-general-starter-<version>.jsonl`, an independently verified filtered projection.
